# Web UI Refinement — Feature Parity with Legacy Swing + Modern Design Upgrade

## Background

The legacy Swing desktop application (pre-v1) contains **13 sidebar modules** with full CRUD operations. The current web UI (v1.1) only implements **7 sidebar modules**, and several of those are incomplete or use placeholder views. This plan brings the web UI to full feature parity while upgrading the visual design to a premium, modern standard.

## Proposed Changes

### Phase 1 — Login Screen & Authentication

> [!IMPORTANT]
> The legacy app requires Employee ID + password login before showing any module. The current web UI has no login gate.

#### [NEW] Login Page
- Full-screen login with Employee ID + Password fields
- Password visibility toggle (eye icon)
- Error/success message states with color coding
- Regulatory compliance footer: "Authorized access only. All activities are monitored and logged per regulatory requirements (FDA / CDSCO / TGA / EFSA)"
- On success → store user session (employeeId, name, role) → redirect to dashboard
- API: Use existing `DatabaseService.getUserByCredentials()` → need to add a `/api/auth/login` endpoint in `ApiServer.java`

#### [MODIFY] ApiServer.java
- Add `POST /api/auth/login` endpoint
- Add `GET /api/auth/roles` to fetch roles list
- Add `GET /api/auth/permissions/{role}` to get role permissions
- Add `PUT /api/auth/permissions/{role}` to save role permissions

### Phase 3 — Reports Module

#### Reporting & Analytics View
Match the legacy 5-button report generator layout with a modern card-based design:

1. **Stock Value Report** (Current Inventory Valuation) — calls `/api/stock` and aggregates
2. **Low Stock / Reorder Report** — filters materials below reorder level
3. **Expiration Date Report (Next 6 Months)** — filters stock by expiry
4. **Supplier Performance Report** — aggregates supplier data
5. **Goods Received History** — lists GRN records

Each report generates a data table with export-to-CSV functionality.

#### [MODIFY] ApiServer.java
- Add `GET /api/reports/stock-value`
- Add `GET /api/reports/low-stock`
- Add `GET /api/reports/expiring`
- Add `GET /api/reports/supplier-performance`
- Add `GET /api/reports/grn-history`

#### API endpoints needed:
- `GET /api/auth/roles` — list all roles
- `GET /api/auth/permissions/{role}` — get permissions for a role

### Phase 6 — Enhanced Quality Dashboard

#### Add missing features from legacy:
- **Batch Details panel** (right side) — structured display with sections: BATCH INFORMATION, QUANTITY & LOCATION, DATES, QC STATUS, TRACEABILITY
- **Status filter dropdown** (top-right) — All, QI Only, QUARANTINE Only, IN_PRODUCTION, APPROVED Only, REJECTED Only
- **Status-driven action buttons** that change based on batch state:
  - IN_PRODUCTION → "Take IPQC Sample" + "View Genealogy"
  - IN_PROCESS_SAMPLE → "Start Testing" + "View Genealogy"
  - UNDER_TEST → "Approve Batch" + "Reject Batch" + "View Genealogy"
- **Batch Genealogy modal** — shows parent batch traceability (FEFO consumed raw materials)
- **Confirm dialogs** for each QC transition with audit trail warnings

### Phase 8 — Visual Design Upgrade

> [!TIP]
> The current web UI already has a solid dark theme with Inter font. These enhancements focus on polish and premium feel.

#### [MODIFY] style.css
- **Login page**: Glassmorphism card with gradient background, animated logo
- **Status badges**: Pill-shaped with color-coded backgrounds (green=Approved, red=Rejected, amber=Pending, blue=In-Process)
- **Table enhancements**: Hover row highlights, sticky headers, better column widths
- **Modal refinements**: Smooth slide-up animations, backdrop blur, scrollable body with sticky footer
- **Sidebar**: Active item indicator bar, hover glow effects, collapse animation
- **KPI cards**: Gradient borders, subtle glow on hover
- **Dark Mode toggle**: Add to sidebar footer (matching legacy)
