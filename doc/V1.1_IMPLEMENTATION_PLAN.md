## Remaining Work

> [!IMPORTANT]
> The main blocker is the **2,287-line `DatabaseService.java`** god-class. It contains MySQL-specific SQL queries using mixed-case table names, `ON DUPLICATE KEY UPDATE`, `CURDATE()`, and MySQL joins. These must be decomposed domain-by-domain into dialect-aware repositories before PostgreSQL can run natively.
